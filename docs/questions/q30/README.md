# <span dir="rtl">خلاصه فصل</span>

<span dir="rtl">فصل آخر یک Feature جدید تولید نمی‌کند؛ کیفیت سیستم تصمیم را می‌سنجد. ارائه باید نشان دهد هر تصمیم از کدام Evidence آمده، چه چیزهایی هنوز Hypothesis هستند و چطور Confluence، Jira، Figma و فایل‌های تحلیلی یک روایت واحد می‌سازند.</span>

## <span dir="rtl">نتیجه فعلی پروژه خانومی</span>

> <span dir="rtl">• Narrative اصلی: Problem → Evidence → Opportunity → Candidate → MVP → Measurement → Economics → Next Experiment.</span>
>
> <span dir="rtl">• Decision wording: Guided Beauty Decision Assistant «Selected for Validation» است، نه Validated Solution.</span>
>
> <span dir="rtl">• Confluence Project Brain و Jira Execution System باید نقش‌های متفاوت اما لینک‌شده داشته باشند.</span>
>
> <span dir="rtl">• Figma V2 Candidate برای Validation است؛ usability outcome هنوز ادعا نمی‌شود.</span>
>
> <span dir="rtl">• Financial pages باید نسخه‌های speculative قبلی را supersede کنند.</span>
>
> <span dir="rtl">• اسلاید نهایی باید Confidence و Critical Unknownها را پنهان نکند.</span>

> <span dir="rtl">• Official brief برای Scope.</span>
>
> <span dir="rtl">• Confluence برای evidence/decision history.</span>
>
> <span dir="rtl">• Jira برای execution artifacts، بدون ادعای Done جعلی.</span>
>
> <span dir="rtl">• Figma برای prototype artifact.</span>
>
> <span dir="rtl">• Standalone DECAF docs برای quantification traceability.</span>

## <span dir="rtl">Cap Rules و Penaltyها</span>

> <span dir="rtl">• هر تناقض Material بین Confluence/Jira/Figma/Presentation حداقل 10 امتیاز Penalty دارد.</span>
>
> <span dir="rtl">• استفاده از claim superseded مثل cost 500M یا ROI +63٪ تا زمان اصلاح، Confidence نهایی را Cap می‌کند.</span>
>
> <span dir="rtl">• Selected for Validation نباید در اسلاید به Validated Solution تبدیل شود.</span>
>
> <span dir="rtl">• هر عدد باید Source/Assumption status داشته باشد.</span>

## <span dir="rtl">مرز ادعا</span>

<span dir="rtl">Fact = داده مستقیم یا منبع رسمی. Evidence = مشاهده‌ای که یک Claim را پشتیبانی می‌کند. Logical Inference = نتیجه منطقی اما غیرمستقیم. Hypothesis = ادعایی که هنوز باید آزمون شود. در ارائه نهایی این چهار وضعیت نباید با هم مخلوط شوند.</span>
