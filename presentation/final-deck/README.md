## ساختار

ارائه شامل ۱۴ اسلاید و برای دفاع ۱۵ تا ۲۰ دقیقه‌ای طراحی شده است:

1. عنوان و پرسش پروژه
2. Evidence Base
3. Current Journey و سیگنال‌های رفتاری
4. Problem Synthesis
5. Feature Selection
6. تجربه جدید و دموی Prototype
7. MVP و Validation Gates
8. KPI و Guardrail
9. معماری Delivery
10. مرز دانسته‌ها و تصمیم بعدی

## کنترل‌ها

- کلیدهای چپ و راست :: حرکت بین اسلایدها
- E :: نمایش Evidence و Caveat
- O :: نمای کلی اسلایدها
- F :: تمام‌صفحه
- P :: بازکردن Prototype
- Swipe :: حرکت در موبایل
- Print :: خروجی PDF مرورگر

## وضعیت ادعا

Prototype کامل است، اما Feature همچنان **Selected for Validation** است. ارائه هیچ Validation، Sprint History، Story Point یا اثر مالی قطعی را جعل نمی‌کند.
