## نقاط برجسته ارائه

- Crawl و Data Lineage برای ۷۶٬۸۳۷ کامنت خام
- Dataset پاک‌سازی‌شده Canonical با ۳۹٬۷۳۷ رکورد
- دو Survey با مجموع ۷۴ پاسخ
- مصاحبه‌های عمیق کاربران و مصاحبه داروخانه
- UX Review برای Landing، Chatbot و Purchase Flow
- DECAF Quantification برای ۳۰ سؤال
- Documentation قابل ردیابی بین Confluence، GitHub، Jira و Figma
- Prototype تعاملی آماده Validation

## ساختار تعاملی

ارائه ۱۴ اسلاید دارد. هر اسلاید دو سطح خواندن ارائه می‌کند:

1. روایت اصلی برای ارائه ۱۵ تا ۲۰ دقیقه‌ای
2. دکمه **جزئیات** برای نمایش داده، روش، Caveat و لینک Artifactهای همان اسلاید

## کنترل‌ها

- کلیدهای چپ و راست :: حرکت بین اسلایدها
- D یا دکمه جزئیات :: داده، روش و Artifact
- E :: نمایش سریع Caveat روی اسلاید
- O :: نمای کلی اسلایدها
- F :: تمام‌صفحه
- P :: بازکردن Prototype
- Swipe :: حرکت در موبایل
- Print :: خروجی PDF مرورگر
