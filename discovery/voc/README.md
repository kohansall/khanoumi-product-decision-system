# Voice of Customer

Lineage :: `raw anonymized → cleaned anonymized → analysis → synthesis → decision`

- Raw owner :: `raw/manifest.json` و CSV shardهای همان Dataset منطقی
- Clean owner :: `cleaned/manifest.json` و CSV shardهای همان Dataset منطقی
- Dashboard :: `interactive-dashboard/index.html`

محدودیت :: Commentها self-selected هستند و شیوع Theme در آن‌ها معادل شیوع در کل کاربران خانومی نیست.

Sharding فقط برای انتقال و نگهداری GitHub است؛ هر Manifest یک Dataset canonical را با Header یکسان و ترتیب پایدار تعریف می‌کند، نه چند Evidence مستقل.
