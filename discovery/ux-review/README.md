# UX Review

این بخش مشاهده سه جریان موبایل خانومی را ثبت می‌کند:

- Home و Landing
- Chatbot
- PDP تا Cart و Checkout

## Artifact اصلی

- [گزارش سه جریان](./three-flow-review.md)

## وضعیت فایل‌های ویدئویی

ویدئوهای خام در Repository عمومی قرار نگرفته‌اند:

- فایل Home حدود ۱۲۹ مگابایت است و از سقف عادی GitHub عبور می‌کند.
- فایل Checkout شامل شماره تلفن و نشانی است.
- یک نسخه تکراری از ویدئوی Home نیز در آرشیو وجود دارد.

گزارش متنی، زمان‌های تقریبی، هش فایل‌ها و تفکیک Observation از Hypothesis را نگه می‌دارد. برای انتشار ویدئوها باید نسخه کم‌حجم و Redacted ساخته شود.

## مرز ادعا

این UX Review یک Expert Review بر اساس Screen Recording است. بدون Product Analytics یا Usability Test نمی‌توان از آن نرخ افت، فراوانی مشکل یا اثر تجاری نتیجه گرفت.
