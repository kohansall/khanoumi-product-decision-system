# روش‌شناسی — DECAF

DECAF چارچوب سفارشی این پروژه برای سنجش دفاع‌پذیری تصمیم‌هاست، نه یک استاندارد دانشگاهی مستقل.

اجزا: Required Data، Evidence Quality، Coverage، Evidence Triangulation، Assumption Dependency، Sensitivity، Cap Rules، Value of Information و Robustness.

طبقات Confidence:
- A: 80–100 — قابل پذیرش و دفاع
- B: 60–79 — قابل استفاده با Caveat
- C: 30–59 — فرضیه/استنتاج؛ نیازمند Validation
- D: 0–29 — فاقد ارزش آماری یا معنایی برای تصمیم قطعی

قاعده مهم: چند نمودار یا خروجی از یک Dataset، چند منبع مستقل نیستند.
