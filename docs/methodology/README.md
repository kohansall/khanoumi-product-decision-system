# روش‌شناسی و DECAF

مسیر تصمیم :: Evidence inventory → source quality → triangulation → conflict audit → sensitivity → confidence cap → next action.

DECAF برای هر سؤال وزن‌های متناسب با Decision Type دارد، اما قواعد پایه ثابت‌اند. امتیاز آن احتمال موفقیت نیست. نبود baseline، ظرفیت فنی، economics یا داده‌ای که بتواند تصمیم را عوض کند، سقف Confidence را پایین می‌آورد.
